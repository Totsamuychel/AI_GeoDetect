❔ Як читати результат
  • Впевненість % — наскільки модель певна у місті.
  • Карта: маркер на передбаченому місті; коло — невпевненість (менша довіра → більший радіус).
  • OOD-банер з'являється, якщо фото, ймовірно, не з цих 4 міст.
  • GeoScore 0–5000 (стиль GeoGuessr): тестова якість моделі, 5000 = ідеально.
  • Карта уваги (для ViT) показує, на що дивилась модель.

Яскравіші зони — куди ViT приділяв більше уваги (attention-rollout по всіх шарах).

Деталі по моделі

Простір ознак (t-SNE)

2D-проєкція ембедингів test-набору. Чіткі кластери = модель добре розділяє міста у просторі ознак.

Калібрування впевненості

Стовпчик — реальна точність у біні впевненості; пунктир — ідеальна калібрація; ECE — середнє відхилення (менше = чесніша впевненість).
